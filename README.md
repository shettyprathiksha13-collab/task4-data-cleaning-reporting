# task4-data-cleaning-reporting
# Data Cleaning & Reporting Automation

## Project Overview
This project demonstrates how Python can automate data cleaning and reporting for a sample business dataset. It uses Pandas, NumPy, and Matplotlib to preprocess data, generate summary reports, and create visualizations.

## Objectives
- Handle missing values.
- Remove duplicate records.
- Standardize text data by removing extra spaces.
- Convert date values into a consistent date format.
- Generate an automated data-cleaning report.
- Create visual summaries of cleaning results and department sales.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib

## Project Workflow
1. Create and inspect the sample business dataset.
2. Identify missing values and duplicate records.
3. Clean and preprocess the data.
4. Generate a summary report.
5. Visualize cleaning results and sales by department.
6. Export the cleaned dataset and report as CSV files.

## Output Files
- `Task4_Data_Cleaning_Reporting.ipynb` — project notebook.
- `cleaned_business_data.csv` — cleaned sample dataset.
- `data_cleaning_report.csv` — automated cleaning summary.

## Conclusion
This project demonstrates how Python can automate basic data-cleaning and reporting tasks, reduce repetitive manual work, and present results through visual summaries.
